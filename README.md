## English

**You recognise the face, but the name won't come.** VisualContext remembers for you: who the person is, where you know each other from and what you agreed last time. It works on an Android phone; on Rokid Glasses it shows right on the lens.

This repository only hosts the app's download files. The source code is private.

### How to get it

1. Request an invite at **[vc.alema.io/en](https://vc.alema.io/en)**. It's a closed, free beta, and every request is approved by hand.
2. Once you're approved, you get an e-mail with the download link and the install steps.
3. Install the APK on an Android 11+ phone. If you have an older version, install the new one over it.

### Privacy

How VisualContext handles your data is explained on [vc.alema.io/en](https://vc.alema.io/en).

### Feedback

Use the feedback button inside the app.
